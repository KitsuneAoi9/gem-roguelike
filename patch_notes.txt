Patch Note 2026/09/21 001

1. Add click and drag feature.
2. A gameover dialogue now will be prompted when there is no more moves available.
3. Added the gem image next to the boon title for the time being. In the future, we will put it inline with descriptions once the effects are finalized and the boon card design are settled. Currently, it would be too messy to implement and very hard to read clustered text.
4. Added gem images to the Gem Stats screen. The image is now shown next to the name. Image + Gem name. Sticking with this format in order to be consistent throughout the game.
5. Changed level one target score to be 2000.
6. Level up screen will now appeared after the cascade combo is finished. Previously, cascade combo was paused the moment the target scored is reached.
7. Added hint features. After 10 seconds of not making any matches, a pulsing golden glow on a cell that's part of a legal move the player hasn't found.
8. Updated Hyperspace special gem

- Hyperspace is now named as Discharger.

- Matched normally (part of a formed match, or hit by a
  chain-reaction blast) -> clears a 3x3 area centered on itself.
  This REPLACES the old row+column+diagonals burst as the
  passive on-match effect.

- Swapped with a Laser Beam -> clears 3 full rows (if the laser
  was a LASER_ROW) or 3 full columns (if LASER_COL), centered on
  wherever the Discharger itself ends up after the swap — instead
  of the laser's usual single row/column.

- Swapped with another Discharger -> the OLD row+column+diagonals
  burst, centered on the swap's destination cell. (i.e. the
  original Star Gem behavior now lives here, swap-exclusive.)

- Swapped with a Hyperspace Star -> mirrors the Hyperstar+Laser
  combo: converts every gem of the Discharger's color into a
  Discharger and detonates them all (each with its own 3x3).

9. Changed the target score forumla.
From
Target Score = ROUND(2000 * (1.35 ^ (Level-1))) * Level + 500 * Pow(1.5, Level)

To
Target Score = ROUND(2000 * (1.25 ^ (Level-1))) * Level + 500 * Pow(1.5, Level)

Patch Note 2026/09/21 002

1. Fixes Hyperstar scoring.
FIXED — the Hyperstar's own cell used to get folded into the
targetGemType matched-group's `length`, which scored IT using the
WIPED color's base value/multiplier instead of its own (whatever
color the Hyperstar itself actually happened to be sitting on).
Now it's pulled out and scored separately, as its own incidental
cell, using its real underlying gem type — same treatment any
other incidentally-cleared cell gets.

2. Fix match score bonus not reflected in the Gem Stat Panel

3. Green/red coloring on boosted/penalized stats for the Gem Stats screen. Green if the value is higher than the default value, red if the value is higher than the default value.

4. Discharge now explodes in the a diamond shape.

    X
  X X X
X X X X X
  X X X
    X

5. Fixed Fanatic boon. Multiplier is now applied correctly.

6. Added history chat. Player now can view score history, boon picked, and boon bought in the history chat.

7. Added Shop. For now, shop will only offers 5 boons. Use score to buy boons.

Shop item price = Base score * Rarity * Inflation Scaling * Base Multiplier

Base score = 500
Rarity = Common: 1x | Uncommon: 1.25x | Rare: 1.75x | Epic: 2.5x | Legendary: 3.25x 
Inflation Scaling = 15% per 5 levels ( after level 5)
Base Multiplier = 1

The target score will go up another 10% every 5 levels.

Levels 1–5: milestoneBand = 0 → factor = 1.10^0 = 1.0 (identical to Part 4's formula)
Levels 6–10: milestoneBand = 1 → factor = 1.10
Levels 11–15: milestoneBand = 2 → factor = 1.21
Levels 16–20: milestoneBand = 3 → factor = 1.331
